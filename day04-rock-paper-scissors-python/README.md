# 🪨 📄 ✂️ Rock, Paper, Scissors Game

A clean, interactive, terminal-based **Rock, Paper, Scissors** game built with **Python**. Play against a randomized computer opponent, view real-time statistics, and test your luck!

---

## ✨ Features

- **Interactive CLI**: Simple and intuitive text-based terminal prompt.
- **Smart Computer Opponent**: Employs random generation logic for unpredictable matchups.
- **Score Tracking**: Tracks wins, losses, and ties dynamically across your active session.
- **Input Validation**: Automatically catches typos and prompts for correct options.
- **Infinite Replay**: Play as many rounds as you want without restarting the script.

---

## 🛠️ Prerequisites

- **Python 3.x** installed on your system.
- No external third-party libraries or dependencies are required.

---

## 📦 Installation & Setup

1. **Clone the repository:**

   ```bash
   git clone git@github.com:HasLid/day04-rock-paper-scissors-python.git
   ```

2. **Navigate to the project folder:**

   ```bash
   cd rock_paper_scissors
   ```

3. **Run the game script:**
   ```bash
   python main.py
   ```
   _(Note: If your file is named something else, replace `main.py` with `game.py` or your exact file name)._

---

## 🎮 How to Play

1. Run the script in your terminal window.
2. Input your move by typing `rock`, `paper`, or `scissors`.
3. The computer instantly displays its randomized choice.
4. The system determines the winner based on classic rules:
   - **Rock** smashes **Scissors**
   - **Paper** covers **Rock**
   - **Scissors** cuts **Paper**
5. Review your current score and decide whether to keep playing or exit.
