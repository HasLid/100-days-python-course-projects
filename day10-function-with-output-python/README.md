# Day 10: Functions with Outputs - Calculator

A simple, interactive command-line calculator built with Python. This project demonstrates the use of functions, dictionaries to map operations, and while loops for continuous calculations. It was created as part of the **100 Days of Code** challenge.

## 🚀 Features

- **Basic Arithmetic:** Supports addition (`+`), subtraction (`-`), multiplication (`*`), and division (`/`).
- **Memory Function:** Allows you to continue calculating using the previous result.
- **Auto-Clear:** Clears the terminal screen when starting a brand new calculation.

## 🛠️ How It Works

1. Enter the first number.
2. Choose a mathematical operator (`+`, `-`, `*`, `/`).
3. Enter the next number.
4. Choose to either continue calculating with the current result or reset and start fresh.

## 💻 Code Structure

- `add()`, `subtract()`, `multiply()`, `divide()`: Core mathematical functions that return outputs.
- `operations`: A dictionary mapping operator symbols to their respective functions.
- `calculator()`: The main recursive function handling user input and the calculation loop.

## 🏃‍♂️ How to Run

Make sure you have Python installed on your system, then run:

```bash
python calculator.py
```
