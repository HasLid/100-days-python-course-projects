# 🏴‍☠️ Treasure Island Game

Welcome to **Treasure Island**, a text-based adventure game built in Python. Navigate through a dangerous island, make the right choices, and find the hidden treasure.

## 🎮 Game Rules

- **Read Carefully:** Every choice determines your survival.
- **Type Choices:** Input commands directly into the terminal (e.g., `left` or `right`).
- **Survival:** One wrong move leads to a trap and immediate game over.
- **Victory:** Find the golden chest to win the game.

## 🚀 How to Run

### Prerequisites

- You need **Python 3 or fully setup vs code** installed on your system.

### Steps

1. Clone this repository to your computer:
   ```bash
   git clone git@github.com:HasLid/day03-treasure-island-python.git
   ```
2. Navigate into the project folder:
   ```bash
   cd treasure-island-game
   ```
3. Run the game:
   ```bash
   python main.py
   ```
